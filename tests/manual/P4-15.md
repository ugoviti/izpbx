# P4-15 — Real FOP2 license after the migration (manual)

The automated test P4-14 checks that the migration from izPBX 20.16 installs
FOP2 from its Debian package and keeps `fop2.cfg`, `fop2.lic` and
`fop2settings.db` of 20.16, but it runs in demo mode: it has no license. This
procedure checks that a **real FOP2 license** still works after the
migration.

A FOP2 license is bound to the network interface it was registered on
(`FOP2_LICENSE_IFACE`, its MAC address). The container must keep that
interface, or the license must be reactivated.

## What you need

- A working izPBX **20.16.22** with a licensed FOP2 (`fop2.lic` in
  `/data/usr/local/fop2`), and its license name and code.
- The same host for the 22.17 test, or at least the same MAC address on the
  licensed interface (`mac_address:` in `docker-compose.yml` if the network
  is a bridge).
- A copy of the data: **never run this on the production volume and
  database.**

## Steps

### 1. Record the license on 20.16.22

```bash
docker exec izpbx sh -c 'cat /etc/sysconfig/fop2; /usr/local/fop2/fop2_server --getinfo'
docker exec izpbx ip -o link show
```

Note the licensed interface, its MAC address and the license status.

### 2. Migrate a copy to 22.17

Stop 20.16, copy `/data` and the databases, then in `.env`:

```bash
IZPBX_MIGRATE_FREEPBX=true
FOP2_ENABLED=true
FOP2_LICENSE_IFACE=<the interface of step 1, if not the first one>
# only if step 4 fails:
# FOP2_LICENSE_NAME=<name>
# FOP2_LICENSE_CODE=<code>
# FOP2_AUTOACTIVATION=true
```

Start the 22.17 image and wait for `healthy`. The log shows
`migration: FOP2 configuration, license and settings of 20.16 kept`.

### 3. Check the interface

```bash
docker exec izpbx sh -c 'cat /etc/default/fop2; ip -o link show'
```

Same interface and MAC address as in step 1.

### 4. Check the license

```bash
docker exec izpbx /usr/local/fop2/fop2_server --test
docker exec izpbx /usr/local/fop2/fop2_server --getinfo
```

Expected: `--test` reports the license as valid (licensed name and number of
buttons), not demo mode. Open `https://<host>/fop2` and log in: no demo
banner.

If the license is "Not Found" (different MAC address), set
`FOP2_LICENSE_NAME`, `FOP2_LICENSE_CODE` and `FOP2_AUTOACTIVATION=true`,
recreate the container and repeat step 4: the fop2 step reactivates the
license. The license code never appears in `docker logs` (masked).
