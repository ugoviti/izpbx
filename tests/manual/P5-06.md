# P5-06 — chan_dongle with a real USB modem (manual)

The automated test P5-05 covers the software side of chan_dongle on izPBX
22.17 (module loaded, `dongle show devices`, reloads). This procedure checks
what only real hardware can show: an outgoing call and an SMS through a 3G
USB modem with a SIM card.

## What you need

- A Huawei 3G USB modem supported by chan_dongle (for example E1550, E169,
  E173, K3765) with **voice enabled** firmware, and a SIM card with credit
  and no PIN (or the PIN disabled).
- A host where the modem appears as `/dev/ttyUSB*` (`lsusb`, `dmesg`); if it
  appears as a storage device, switch it with `usb_modeswitch` on the host.
- izPBX 22.17 with FreePBX installed (or Asterisk alone: `IZPBX_ENABLED=false`,
  `ASTERISK_ENABLED=true`).
- A phone number to call and to receive the SMS.

## Steps

### 1. Find the modem ports on the host

```bash
ls -l /dev/ttyUSB*        # usually 3 ports: the first is data, the second audio
dmesg | grep -i ttyUSB
```

### 2. Give the ports to the container

In `docker-compose.yml` (izpbx service):

```yaml
    devices:
      - /dev/ttyUSB0:/dev/ttyUSB0
      - /dev/ttyUSB1:/dev/ttyUSB1
      - /dev/ttyUSB2:/dev/ttyUSB2
```

The ports must be readable and writable by the `asterisk` user (uid 1000)
inside the container: check the group of `/dev/ttyUSB*` on the host
(`dialout`) and, if needed, add `group_add: [dialout]` or set the permissions
with a udev rule.

### 3. Configure dongle.conf

Write `/data/etc/asterisk/dongle.conf` (the 20.16 file can be reused as it
is; the fixture of the automated tests has the same layout):

```ini
[general]
interval=15

[defaults]
context=from-trunk
group=0
disablesms=no
language=it
initstate=start

[dongle0]
audio=/dev/ttyUSB1
data=/dev/ttyUSB2
imei=<the IMEI printed on the modem>
```

Then `docker exec izpbx asterisk -rx 'module reload chan_dongle.so'`.

### 4. Check the device

```bash
docker exec izpbx asterisk -rx 'dongle show devices'
docker exec izpbx asterisk -rx 'dongle show device state dongle0'
```

Expected: State `Free`, RSSI greater than 0, the provider name, the IMSI.

### 5. Outgoing call

From an extension, through a trunk "Custom" with dial string
`Dongle/dongle0/$OUTNUM$` and an outbound route, or from the CLI:

```bash
docker exec izpbx asterisk -rx 'channel originate Dongle/dongle0/<number> application Playback demo-congrats'
```

The phone rings, answers, and the audio is heard both ways.

### 6. SMS

```bash
docker exec izpbx asterisk -rx 'dongle sms dongle0 <number> izPBX 22.17 test'
```

The phone receives the SMS. Send an SMS to the SIM number: the Asterisk log
(`/var/log/asterisk/full`) shows the incoming SMS on context `from-trunk`
(extension `sms`).
